# OMAR / FIT — المشروع الكامل

موقع عربي للتمارين الأسبوعية، مع رسوم حركة محلية، سجل وزن وتكرارات لكل جولة، مؤقت راحة 60 ثانية، وخطط مستقلة لكل أسبوع.

## الحفظ والخصوصية

النسخة المنشورة تستخدم قاعدة بيانات D1 وسجلات مرتبطة بهوية المستخدم من بوابة Sites. انتظار حالة «تم الحفظ في حسابك» يؤكد اكتمال الحفظ. عند انقطاع الاتصال تبقى التعديلات معلّقة على الجهاز حتى عودته. يتوفر تصدير واستيراد نسخة JSON من صفحة التقدم. تصدير المشروع لا يحتوي بيانات المستخدم أو أسرار الدخول.

تحتفظ التعديلات بتاريخها على الخادم، وتبقى نسخة من البيانات القديمة عند الترحيل. دمج نسخ احتياطية لا يمسح سجل الحساب. عند تعديل السجل نفسه من جهازين، تحفظ آخر كتابة وتبقى المراجعات في سجل التغييرات.

## التشغيل المحلي

المتطلبات: Node.js 22.13 أو أحدث وpnpm 11.25.0. هذا مشروع خادم؛ رفعه لاستضافة ملفات ساكنة فقط لا يوفر الحفظ الخاص.

```bash
pnpm install
pnpm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_open_magma.sql
pnpm run start
```

نفذ أمر تهيئة قاعدة البيانات مرة واحدة فقط لقاعدة محلية جديدة. افتح العنوان الذي يظهر في الطرفية. إذا ظهرت بوابة الدخول المحلية استخدم مسار `/signin-with-chatgpt` الخاص بالمحاكاة المحلية. تشغيل التطوير: `pnpm run dev`؛ يتيح المعاينة المحلية دون حساب مع تنبيه صريح أن الحفظ على الجهاز فقط.

```bash
pnpm run test
```

اختبارات الخادم تتحقق من عزل الحسابات، تكرار الطلبات دون مضاعفة، استعادة الحفظ بعد انقطاع الاتصال، واستقلال الأسابيع. ملف SQLite المحلي وبيانات المعاينة مستبعدان من المشروع.

## الملفات

- `content/site.html`: الصفحة العربية.
- `public/app.js`: الواجهة، مؤقت الراحة، سجل الجولات.
- `public/data.js`: مكتبة التمارين والجدول الافتراضي.
- `public/balance.css`: المزيج الأبيض والداكن.
- `public/workout-model.js`: الأسابيع، الترحيل والنسخ الاحتياطية.
- `public/cloud-store.js`: الحفظ وطلبات المزامنة المعلقة.
- `server/records.mjs`: التحقق من الهوية وقراءة وكتابة السجلات.
- `db/schema.ts` و`drizzle/`: مخطط قاعدة البيانات وترحيلاتها.

لإعادة النشر عبر Sites تُستخدم إعدادات `.openai/hosting.json` وربط `DB`؛ الخادم يعتمد على رأس الهوية الموثوق من البوابة. لا يجوز الاعتماد على رأس يرسله الزائر مباشرة عند نقله إلى استضافة أخرى: يلزم حينها بوابة تحقق مكافئة. قاعدة البيانات المحلية منفصلة عن الحساب المنشور.

## البرنامج

السبت صدر وتراي، الأحد ظهر وباي، الاثنين أرجل وبطن، الثلاثاء استشفاء، الأربعاء أكتاف وترابيس، الخميس باي وتراي، الجمعة راحة. لكل جولة وزن وتكرارات فعلية وإنجاز منفصل. خطة أسبوع جديد تنسخ أقرب أسبوع سابق؛ تعديل أسبوع موجود لا يغير أسابيع أخرى. يمكن تخصيص التمارين والجولات والتكرارات من الواجهة.

البرنامج عام ويُعدل بحسب الخبرة والتعافي. الرسوم محفوظة محلياً؛ راجع `MEDIA-CREDITS.md` ومجلد `licenses` لحقوق الوسائط والخطوط.

## تجربة الحصة والتنبيهات

- وضع الحصة يعرض تمريناً واحداً مع الحركة والجولات والتنقل السابق/التالي. زر عرض كل التمارين يعيد العرض الكامل.
- المقارنة لكل جولة مكتملة من الحركة نفسها واليوم نفسه في الأسبوع السابق، وتعرض تغير الوزن والتكرارات منفصلين.
- التقرير الشهري يعرض الحصص والجولات المكتملة ونسبة الالتزام بالأيام المجدولة المنقضية. الرسم لأعلى وزن مكتمل من التمرين المحدد في كل يوم.
- بدائل منتقاة من المكتبة؛ يظهر وصف اختلاف الحركة، ويحفظ الاستبدال في خطة الأسبوع فقط مع بقاء السجل القديم. إن لم يتوفر بديل مناسب تظهر رسالة واضحة.
- ملاحظات التمرين محفوظة خاصة بالحساب وتستمر بين الأسابيع. النسخ الاحتياطية تتضمنها؛ الاستيراد يحفظ الملاحظة الحالية ويستورد المفقودة.
- ملف manifest وأيقونات الهاتف تتيح الإضافة للشاشة الرئيسية؛ زر التثبيت يظهر عند دعم المتصفح.
- إذن إشعارات النظام يُطلب فقط عند ضغط زر التفعيل. الصوت والاهتزاز وإشعارات النظام لها إعدادات على الجهاز، وزر تجربة مستقل.
- إشعار الراحة يصدر أثناء تشغيل الصفحة؛ ليس نظام Push مجدولاً على الخادم. بعد إغلاق الصفحة لا يصل تنبيه جديد، وقد يؤخر الهاتف المؤقت عند قفل الشاشة/تعليق المتصفح. يعاد حساب الوقت عند العودة.
- على iPhone يلزم فتح الموقع من أيقونة الشاشة الرئيسية لإتاحة إشعارات الويب في الأنظمة الداعمة. الاهتزاز البرمجي عبر Vibration API غير مدعوم في متصفحات iPhone. الصوت يتأثر بالصامت وعدم الإزعاج.
- Service Worker يعرض الإشعارات ويفتح الحصة عند الضغط، ولا يخزن استجابات API أو بيانات خاصة في Cache Storage.
