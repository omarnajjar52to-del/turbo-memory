# نار NAAR: موقع مطعم بيتزا وسندويشات وسناكات

موقع عربي/إنجليزي (RTL و LTR) مبني بـ HTML و CSS و JavaScript عادي، بدون أي أدوات بناء.
يفتح من أي استضافة ملفات ثابتة (Netlify، GitHub Pages، Vercel، أو أي سيرفر).

## اللي فيه
- شاشة ترحيب متحركة، يختار فيها الزبون اللغة (وبالزيارات الجاية تصير ترحيب قصير وتسكّر لحالها).
- قسم رئيسي فيه بيتزا تدور، وجمر متطاير، وبخار، وشارات متحركة.
- "الأكثر طلباً": شريط أفقي يتحرك مع السكرول على الكمبيوتر، ويتسحب بالإصبع على الموبايل.
- منيو فيه 27 صنف، مع فلترة متحركة وبحث بالعربي والإنجليزي.
- صفحة لكل صنف: الحجم، الإضافات، درجة الحرارة، الكمية، وملاحظة للمطبخ.
- سلة بثلاث خطوات: السلة، ثم التفاصيل، ثم التأكيد. فيها شريط للتوصيل المجاني، وتحقق من الحقول، وإيصال بشكل فاتورة.
- إرسال الطلب على واتساب برسالة جاهزة، أو لرابط API إذا حطيته.
- عروض اليوم مع عدّاد تنازلي، وأوقات دوام تبيّن "مفتوح الآن" حسب توقيت المطعم.
- يحترم إعداد "تقليل الحركة" بالجهاز، ويشتغل بلوحة المفاتيح وقارئ الشاشة.

## كيف تعدّله
| الملف | شو تغيّر فيه |
|------|---------------|
| `assets/js/config.js` | **رقم الواتساب**، رقم الهاتف، العملة، رسوم التوصيل، الحد الأدنى، أوقات الدوام، العنوان، رابط الخرائط، روابط السوشال |
| `assets/js/menu.js` | الأصناف والأسعار والإضافات والصور والعروض |
| `assets/js/i18n.js` | كل نصوص الموقع بالعربي والإنجليزي |
| `assets/css/styles.css` | الألوان والخطوط (المتغيرات بأول الملف) |
| `assets/img/` | الصور (WebP). بدّلها بصور أكلك الحقيقية بنفس الأسماء |

> مهم قبل الإطلاق: حط رقم واتساب المطعم بـ `whatsapp` في `config.js` (أرقام فقط، مثل `9647701234567`).
> إذا تركته فاضي، واتساب يفتح ويطلب من الزبون يختار المحادثة بنفسه.

## التشغيل محلياً
افتح `index.html` مباشرة، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 8080
```

## نظام التصميم
مولّد بسكيل **ui-ux-pro-max**. التفاصيل والقرارات بالملف `design-system/naar/MASTER.md`.
الخطوط: Badeen Display للعناوين العربية، وDela Gothic One للعناوين الإنجليزية، وAlexandria للعناوين الصغيرة والأرقام، وReadex Pro للنصوص.
