# نار — تجربة طلب بأسلوب التطبيق

موقع عربي وإنجليزي يعمل مباشرة من index.html أو أي استضافة ملفات ثابتة.

## النسخة الحالية
- وضع نهاري وليلي من زر الشمس أو القمر، مع حفظ اختيار الزائر. يبدأ حسب إعداد الجهاز إذا لم يختر وضعًا.
- تنقل ثابت للهاتف: الرئيسية، المنيو، العروض والسلة. زر رجوع المتصفح يعيد صفحة التصفح السابقة.
- عمودان للمنتجات على الهاتف، ثلاثة على التابلت وأربعة على الكمبيوتر.
- بحث وفلاتر مباشرة، مع الحفاظ على الأسعار والإضافات والسلة وخطوات الطلب.
- صور توضيحية جديدة للأصناف الـ27، وشعار SVG بتمييز مناسب للوضعين.
- تم استبدال دوران الصور وميلان البطاقات وانتقالات التمرير الطويلة بتفاعل مباشر وثابت.

## التخصيص
- assets/js/config.js: رقم الواتساب والهاتف والعنوان والتوصيل وروابط التواصل.
- assets/js/menu.js: الأصناف والأسعار والإضافات.
- assets/js/i18n.js: النصوص العربية والإنجليزية.
- assets/css/app-ui.css: الواجهة والوضعان وقياسات البطاقات.
- assets/js/app-ui.js: الثيم والتنقل السفلي وحفظ الاختيار.

رقم واتساب المطعم في الملف الأصلي ما زال فارغًا. ضع الرقم الدولي لاستقبال الطلبات مباشرة. لا تحتاج حزم أو بناء لتشغيل الموقع.

الصور توضيحية مولّدة بالذكاء الاصطناعي وليست تصويرًا فعليًا لطلبات المطعم.
