# معرض مجموعة وسيم السيد — LG / LIVING

نسخة 33 توسّط عناصر واجهة الهاتف وتعرض مشهدين متحركين داخل شاشة تلفزيون LG. تفتح الواجهة تلقائيًا بعد شاشة الهوية أو عند لمسها. تتضمن الواجهة كتالوجًا وبحثًا وفلاتر ومفضلة ومقارنة حتى 3 منتجات من الفئة نفسها ودليل اختيار آلي يعتمد على البيانات المدخلة.

## التشغيل

افتح `index.html` أو ارفع محتويات المجلد إلى استضافة ملفات ثابتة. هذا هو مدخل الموقع لجميع قياسات الشاشة.

## تعديل المعرض والمنتجات

حرر `SHOP` و `PRODUCTS` في `catalog-data.js`. لكل منتج: `id`, `category`, `name`, `model`, `images`, `price`, `availability`, `features`, `specifications`, `variants`. حالة التوفر: `available`, `unavailable`, `order`, `unknown`. الصور المحلية في `assets/`. أضف رقم واتساب إلى `SHOP.whatsapp` بصيغة دولية لتفعيل الرابط المباشر؛ بدونه يظهر نص الاستفسار للنسخ.

الموديلات الستة الحقيقية في هذه النسخة موثقة بصور الملصقات التي وفرها المعرض؛ بطاقات SVG الواضحة نسخ مقروءة للمواصفات. صور الأجهزة المعزولة تمثيلات بصرية وليست إثباتًا لشكل الموديل الدقيق. المنتجات ذات `demo:true` نماذج توضيحية، ولا تمثل مخزون المعرض. حالات التوفر ليست ربطًا مباشرًا بالمخزون. لا تُعرض الأسعار في الواجهة الحالية.

لا توجد مكتبات بناء أو قاعدة بيانات. تحفظ المفضلة والمقارنة واللغة محليًا في المتصفح عبر `localStorage`.

صورة الواجهة الختامية تصوّر بصري مولّد مستوحى من الصورة المقدمة، وليست صورة توثيقية للمحل الحقيقي. النص الدعائي موضوع في HTML وقابل للتعديل ولا يوجد داخل الصورة.
