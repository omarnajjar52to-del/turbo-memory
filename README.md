# OMAR GYM — منصة تدريب الكوتش والمشترك

إصدار PERFORMANCE بتاريخ 1 نوفمبر 2026. هوية سوداء وبيضاء مع أحمر رياضي، عربي RTL، واجهتان للإدارة والمشترك، وحسابات مستقلة باسم مستخدم وكلمة مرور. التطبيق لا يحتاج حساب ChatGPT عند الدخول.

## رحلة الاستخدام

1. صاحب النادي يختار «أنشئ حساب الإدارة»، ويحدد اسم الدخول وكلمة المرور واسم النادي.
2. الإدارة تضيف المشترك: الاسم، اسم الدخول، كلمة مرور مؤقتة، الهدف، الهاتف، العمر، الطول، وزن البداية، الملاحظات ومدة الاشتراك والرسوم.
3. تظهر بيانات الدخول مرة واحدة؛ ينسخها الكوتش ويشاركها مع المشترك بشكل خاص.
4. يعيّن الكوتش قالباً للمشترك، أو يصمم له أسبوعاً خاصاً من مكتبة 29 حركة محلية. يمكن تعديل الأيام والجولات والتكرارات.
5. المشترك يدخل باسم المستخدم وكلمة المرور، ويختار كلمته الخاصة عند أول دخول، ثم تظهر له تمارينه فقط.
6. يسجل الوزن والتكرارات لكل جولة، مع مؤقت راحة يحدده الكوتش وتنبيهات بحسب دعم الجهاز، وسجل تقدّم لأوزانه وجولاته.

## الصلاحيات

- المالك: مساحة التدريب، المشتركون والمدربون، البرامج وتخصيصها وإعدادات النادي.
- الكوتش: المشتركون والبرامج والتخصيص، مع إعادة تعيين كلمات مرور المشتركين؛ لا يصل إلى إعدادات المالك.
- المشترك: ملفه وبرنامجه وجولاته وتقدّمه فقط. لا يمكنه إنشاء حسابات للآخرين أو تعديل النادي والبرامج أو الاطلاع على نادٍ آخر.
- لكل نادٍ بيانات منفصلة، ويمكن لمالك واحد إنشاء حتى خمسة نوادٍ. أسماء الدخول فريدة على مستوى المنصة.

## الحفظ والحسابات

- قاعدة بيانات D1 على الخادم، دون كلمات مرور نصية أو مفاتيح في الواجهة.
- كلمات المرور باستخدام PBKDF2-SHA256 مع 100,000 دورة وملح عشوائي مستقل لكل حساب؛ هو الحد الذي يدعمه Workerd.
- جلسات عشوائية 256-bit مدتها 7 أيام، مخزنة على الخادم كبصمة SHA-256. الكوكي HttpOnly + SameSite=Strict، وتصبح Secure على HTTPS.
- فحص Origin لكل طلب POST، وحد للطلب، والتحقق من النادي والدور في الخادم، وتقييد محاولات الدخول والتسجيل.
- تغيير كلمة المرور أو إعادة تعيينها يلغي جلسات الحساب السابقة. الحسابات الجديدة للمشتركين والمدربين تحتاج تغيير الكلمة المؤقتة قبل عمليات الكتابة.
- لا يوجد بريد استعادة تلقائي؛ المشترك يطلب إعادة التعيين من الكوتش. استعادة حساب المالك تتطلب مشغل الخادم؛ لا توجد كلمة مرور رئيسية أو باب خلفي.
- البرنامج المعيّن نسخة مستقلة عن القالب. تُحفظ نسخ التعيين في assignment_versions، وتبقى الجولات السابقة عند إعادة تعيين البرنامج.

## نطاق الإصدار

الواجهة مركزة على الحسابات، الصلاحيات، برامج الأسبوع، ملفات المشتركين، الجولات والأوزان ومؤقت الراحة وتصدير JSON. أزيلت شاشات الحضور والدفعات من الواجهة. تبقى الجداول والعمليات القديمة في الخادم للتوافق وحفظ البيانات السابقة؛ لم تُحذف أي سجلات. لا توجد بوابة دفع إلكترونية أو تطبيق منشور في المتاجر أو فوترة SaaS آلية.

الواجهة تعرض سجل التدريب لآخر 90 يوماً (حتى 10,000 جولة للطلب)، وحتى 1,500 عضوية و250 قالباً للنادي. التخزين يحتفظ بالسجل الأقدم؛ يلزم إضافة صفحات وترشيح زمني/أرشفة قبل توسيع التشغيل لنوادٍ ضخمة. تصدير JSON هو نسخة من البيانات المعروضة المصرح بها، وليس تفريغاً كاملاً لكل سجل قاعدة البيانات.

قبل البيع التجاري الواسع: مراجعة أمن مستقلة، نسخ احتياطي واستعادة لقاعدة البيانات، سياسة خصوصية وعقود مناسبة، ومراقبة وتحديد حدود التشغيل. أذونات المالك والكوتش والمشترك مختبرة آلياً؛ هذا لا يحل محل مراجعة مستقلة.

## تشغيل محلي

المتطلبات: Node >=22.13 وpnpm 11.25.0.

```bash
pnpm install
pnpm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_big_hellcat.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_bored_rachel_grey.sql
pnpm run start
```

تهيئة الترحيل مرة واحدة فقط لكل قاعدة محلية جديدة. بعد ذلك افتح العنوان الذي يطبعه Wrangler وأنشئ حساب إدارة محلياً. `pnpm run dev` للتطوير. ملفات الحالة المحلية وكلمات المرور والجلسات وبيانات الاختبار مستبعدة من الأرشيف.

```bash
pnpm test
```

تتحقق الاختبارات من عزل النوادي، خصوصية المشترِك، صلاحيات المدرب، إنشاء الحسابات، تغيير وإعادة تعيين كلمة المرور، إلغاء الجلسات، الجولات، الحضور غير المكرر، فصل نسخة البرنامج عن القالب، منع CSRF وتقييد المحاولات.

## الاستضافة

مشروع خادم Vinext على Cloudflare Workers وD1، وليس ملفات ثابتة. لا يعمل رفعه وحده إلى GitHub Pages؛ GitHub يمكنه تخزين المصدر، أما الحسابات وقاعدة البيانات فتحتاج بيئة خادم داعمة.

إعداد Sites في `.openai/hosting.json` يربط DB. Worker يحافظ على تكامل الاستضافة، بينما حسابات المنتج تستخدم جلسات التطبيق المستقلة ولا تثق برؤوس هوية يرسلها الزائر. واجهة الدخول متاحة للزائر، والبيانات خلف الجلسة والصلاحيات. لم يُغيّر الموقع الشخصي OMAR FIT ولا قاعدة بياناته.

## نسخة الهاتف والآيباد

أعيد تنظيم الواجهة لتعمل كتطبيق ويب: شريط تنقل سفلي ثابت، أدوات الإدارة في قائمة المزيد، وبطاقات للمشتركين والسجلات على الهاتف. الآيباد يعرض أقسام المتابعة بجانب بعضها. الألوان أسود وأبيض مع أحمر رياضي. الهيكل طولي بعرض تطبيق هاتف حتى على الشاشة الكبيرة، مع حصة يومية وعبارات تحفيزية متغيرة. واجهة التمارين أكبر وتدعم إدخال الوزن والتكرارات بلوحة الأرقام. على Safari: مشاركة ثم إضافة إلى الشاشة الرئيسية. على Android: تثبيت التطبيق من قائمة المتصفح. البيانات مرتبطة بالحساب والخادم، ولا يحذفها تحديث الواجهة. هذا تطبيق ويب قابل للتثبيت وليس ملف متجر iOS أو Android.

المكتبة تدعم التصفية حسب العضلة والبحث. الواجهة الأساسية للكوتش: الرئيسية، المشتركون، البرامج، التمارين؛ وللمشترك: الرئيسية، برنامجي، تقدّمي، التمارين. الحركات تعمل داخل البطاقات مع شرح الأداء في نافذة مستقلة. التحكم بالصوت والإشعارات من قسم الراحة.

## NEXT: رحلة اختيار المستوى

- قبل الدخول تظهر بطاقتان كبيرتان: مبتدئ ومحترف؛ دخول الكوتش منفصل.
- اختيار المشترك محفوظ في training_profiles على الخادم، معزول حسب النادي والحساب. يظهر للكوتش على بطاقة المشترك وملفه. يمكن تغييره من شارة المستوى في الرئيسية.
- الاختيار لا يستبدل برنامج الكوتش ولا يغير جولات موجودة. للمبتدئ تظهر ملاحظة تقنية إضافية أثناء الحصة.
- الحصة مشغّل تمرين واحد في كل مرة، بداخله الفيديو والجولة النشطة وسجل الجولات.
- الكوتش يبدأ برنامجاً جديداً باختيار مبتدئ (قالب جسم كامل ٣ أيام) أو محترف (قالب ٥ أيام)، ثم يراجع ويعدل قبل الحفظ والتعيين. القوالب نقطة بداية يراجعها الكوتش وفق المشترك.
- الترحيل 0001 يضيف جدول المستوى فقط؛ لا يغير أو يحذف أي سجل قديم. على قاعدة محلية موجودة طبّق الترحيلات المفقودة فقط، ولا تعِد 0000.

## PERFORMANCE: نظام التمرين والأوزان

1. افتح «برنامجي» للجدول الأسبوعي. اختر اليوم، راجع ترتيب الحركات، ثم افتح الحصة.
2. الحصة تعرض تمريناً واحداً في كل مرة، مع الفيديو المحلي وأهداف الجولات والتكرارات والراحة.
3. بطاقة الجولة النشطة فيها وزن بالكيلوغرام وتكرارات/ثوانٍ بأزرار كبيرة، مع آخر أداء مسجل وزر لاستخدامه. القيم السابقة اقتراحات تتطلب ضغط الحفظ.
4. حفظ الجولة يكتب سجلاً واحداً للأسبوع واليوم والحركة والجولة ثم ينتقل للجولة غير المكتملة التالية. تعديل جولة محفوظة يحدّثها دون مضاعفة عدد الجولات.
5. مسودات الإدخال تبقى في الذاكرة أثناء التنقل داخل الحصة؛ تُحفظ في الخادم بعد الضغط على حفظ فقط.
6. الراحة تتبع قيمة rest في الخطة، مع زيادة ٣٠ ثانية وإيقاف وإنهاء. الخطط القديمة دون rest تستخدم ٦٠ ثانية. وقت الراحة اختياري لكل حركة بين ٣٠ و٣٠٠ ثانية ويتحقق منه الخادم.
7. يمكن التنقل بين التمارين أو مراجعة ملخص الجولات الناقصة والمنجزة. لا يظهر «أنجزتها» إلا إذا اكتملت جولات الخطة فعلياً.
8. من حساب الكوتش: البرامج ← راجع خطة ٥ أيام أو خطة المبتدئ ← تعديل الجولات والتكرارات والراحة ← حفظ ← اختيار المشترك للتعيين.

القالب المتقدم: السبت صدر وظهر A، الأحد أرجل وبطن A، الاثنين استشفاء، الثلاثاء صدر وظهر B، الأربعاء أرجل وأكتاف B، الخميس باي وتراي مستقل، الجمعة استشفاء. القالب الأولي للمبتدئ ثلاث حصص جسم كامل تتخللها أيام استشفاء. يدعم الدليل دورة مراجعة ٤ أسابيع، ولا يغيّر الأحمال تلقائياً.

البرامج المعدّلة والحسابات القائمة لا تُستبدل عند تحديث الواجهة. القالب الجديد جاهز للمراجعة والتعيين من الكوتش، ويستخدم للنادي الجديد. لا توجد تغييرات جديدة على مخطط قاعدة البيانات في إصدار PERFORMANCE.

مراجع إعداد القوالب العامة: https://acsm.org/resistance-training-guidelines-update-2026/ و https://doi.org/10.1249/MSS.0b013e3181915670 . التوزيع النهائي اقتراح برمجي يراجعه الكوتش وفق المشترك، وليس خطة شخصية موحّدة للجميع.

## النسخة النظيفة ومسارا الدخول

- البداية: «عندي اشتراك مع كوتش» للدخول بحساب يمنحه المدرب، أو «برنامجي الخاص» لحساب مستقل.
- الحساب المستقل ينشئ مساحة شخصية خاصة على الخادم، يختار مبتدئ/محترف، ويعدل الأيام والتمارين والجولات والراحة بنفسه. لا يستطيع تعديل حسابات أو برامج النادي.
- لا توجد حسابات إدارة أو مشتركين أو كلمات سر افتراضية. أنشئ حساب الكوتش وكلمة سره بنفسك عند التشغيل الأول.
- حُذفت بيانات العرض الوهمية. مكتبة التمارين والقوالب والفيديوهات تبقى ضمن التطبيق.
- ملف ZIP لا يحتوي قواعد بيانات أو جلسات أو ملفات بيئة أو نسخ احتياطية. يبدأ فارغ الحسابات عند توصيل قاعدة بيانات جديدة. رفعه فوق استضافة تستخدم قاعدة موجودة لا يمسح سجلاتها.
- النسخة القابلة للتنزيل لا تحمل هوية نشر الموقع الحالي، حتى لا تعيد نشرها فوقه بالخطأ. مشروع GitHub جديد يحتاج استضافة Worker وقاعدة D1 خاصة به.
- للاختبار المحلي بقاعدة قائمة، طبّق فقط الترحيل الجديد `drizzle/0002_dark_raza.sql`؛ لا تعِد تطبيق الترحيلات القديمة.
