# OMAR / FIT — مشروع عمر النجار

المشروع الكامل لآخر نسخة منشورة، بتقسيم عضلتين لكل يوم تدريب ورسوم الحركات من Fitness Programer.

## التشغيل على جهازك

الموقع مكتوب بـ HTML وCSS وJavaScript، ولا يحتاج إلى تثبيت مكتبات أو تنفيذ build.
يجب تشغيله عبر خادم محلي؛ فتح index.html بالنقر المزدوج عبر file:// لا يشغّل وحدات JavaScript بالشكل الصحيح.

### باستخدام Node.js

1. ثبّت إصداراً مدعوماً من Node.js إن لم يكن موجوداً.
2. فك ضغط المشروع وافتح مجلد `omar-fit`.
3. في Windows شغّل `START-WINDOWS.bat`، أو افتح Terminal داخل المجلد واكتب:

```sh
npm start
```

4. افتح `http://localhost:8000`.
5. للإيقاف اضغط Ctrl+C في نافذة الطرفية.

يمكن تشغيل الخادم مباشرة أيضاً:

```sh
node start-server.mjs
```

### بديل باستخدام Python

افتح Terminal داخل مجلد المشروع ثم نفّذ:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

ثم افتح `http://localhost:8000`.
يمكن أيضاً استخدام إضافة Live Server في VS Code.

## رفع الموقع على الاستضافة

ارفع ملفات الموقع إلى مجلد النشر بحيث يكون `index.html` في الجذر، مع الحفاظ على مسارات الملفات والمجلدات.
الملفات اللازمة هي `index.html` و`style.css` و`fonts.css` و`app.js` و`data.js` و`plan-storage.js` ومجلد `assets` كاملاً.
لا تحتاج إلى قاعدة بيانات أو API keys أو عملية build.

### GitHub Pages

1. ضع ملفات الموقع السابقة في جذر المستودع أو داخل مجلد docs.
2. من Settings → Pages اختر Deploy from a branch.
3. اختر الفرع والمجلد الذي يحتوي index.html ثم احفظ.
4. احتفظ بمجلد assets وكل ملفات JavaScript وCSS بجانب index.html.

تسجيل الدخول الخاص برابط ChatGPT الأصلي خدمة توفرها تلك الاستضافة، وليس جزءاً من هذا المشروع الثابت.
عند رفع هذه النسخة إلى استضافة أخرى، اضبط صلاحيات الوصول من الاستضافة إذا أردتها خاصة.

## ملفات المشروع

| الملف | الغرض |
|---|---|
| index.html | هيكل الواجهة العربية |
| style.css | التصميم الداكن والتجاوب مع الشاشات |
| fonts.css | تعريف الخطوط المحلية |
| app.js | الجدول والمكتبة ومؤقت الراحة وتسجيل الإنجاز |
| data.js | التمارين، مصادر الرسوم، المجموعات والتكرارات، والجدول الافتراضي |
| plan-storage.js | نقل الجدول إلى التقسيم الجديد مع الاحتفاظ بالخطة السابقة |
| assets/hero.png | الصورة الرئيسية |
| assets/motion | الرسوم المتحركة GIF وصور المعاينة WebP |
| assets/*.ttf | خطوط Cairo وBarlow Condensed |
| start-server.mjs | خادم محلي للتطوير فقط |
| START-WINDOWS.bat | تشغيل الخادم محلياً على Windows |

## تخصيص الجدول

الجدول الحالي:

| اليوم | العضلات |
|---|---|
| السبت | صدر + ترايسبس |
| الأحد | ظهر + بايسبس |
| الاثنين | أرجل + بطن |
| الثلاثاء | أكتاف + ترابيس |
| الأربعاء | صدر + ترايسبس |
| الخميس | ظهر + بايسبس |
| الجمعة | راحة |

يمكن تعديل كل حصة من زر «تخصيص الجدول» داخل الموقع.
لتغيير الجدول الافتراضي برمجياً، عدّل `defaultPlan` في `data.js`.
إذا أردت تطبيق جدول افتراضي جديد على متصفحات حفظت جدولاً سابقاً، غيّر `planRevision` أيضاً.
تُحفظ الخطة السابقة ضمن `planArchive` ولا تُحذف سجلاتها.

## البيانات والحفظ

الحفظ محلي في المتصفح عبر localStorage بالمفتاح `omar-fit-v1`.
الأوزان والمجموعات والخطة المخصصة ليست قاعدة بيانات مشتركة، ولا تتزامن بين الأجهزة أو عناوين المواقع المختلفة.
تصدير السجل من داخل الموقع ينزّل ملف JSON؛ لا تتضمن النسخة الحالية أداة استيراد لهذا الملف.
الحزمة لا تحتوي بيانات تمارينك الشخصية أو سجل المتصفح، بل الكود والأصول والجدول الافتراضي فقط.

## المحتوى والأصول

تحتوي المكتبة على ٢٩ تمريناً، منها ١٠ تمارين مطابقة للصفحة المرجعية المختارة.
الرسوم المتحركة محفوظة محلياً، ولا توجد فيديوهات YouTube أو مشغّلات iframe.
البلانك عرض لوضعية ثابتة، وباقي الحركات صور GIF متحركة.
مصادر الرسوم مذكورة في `MEDIA-CREDITS.md` وداخل data.js وفي واجهة الموقع. احتفظ بنسبة الرسوم لأصحابها.
الصورة الرئيسية مولّدة بالذكاء الاصطناعي. الخطوط محفوظة محلياً؛ تراخيصها مرفقة عند توفرها ضمن licenses.

البرنامج نموذج عام قابل للتخصيص حسب المستوى، وليس تقييماً شخصياً من مدرب.
