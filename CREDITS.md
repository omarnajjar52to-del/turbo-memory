# NAAR — refreshed imagery and identity

All 27 menu photographs and the 3 hero/editorial food images were newly generated using the built-in image generator for this redesign, then optimized to WebP. They are illustrative images, not photographs of actual delivered dishes.

The new logo concept was image-generated; the production SVG logo and favicon were redrawn as clean scalable paths. The SVG contains no external font dependency.

Original site code, menu, prices, configuration, GSAP libraries and font references were retained. Refresh styles and the logo motion scene are in assets/css/refresh.css and assets/js/refresh.js.

The current ordering interface uses app-ui.css and app-ui.js with native browser controls; the earlier GSAP presentation scripts are not loaded. Menu data and prices are unchanged.
