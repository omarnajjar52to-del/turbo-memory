الإصدار: 20261031-github-01 — جميع تحديثات 31 أكتوبر 2026.

## رفع النسخة الصحيحة

1. فك ضغط الملف. ارفع محتوياته كلها إلى جذر مستودع الموقع الحالي، واستبدل الملفات المتطابقة، وخصوصاً index.html. لا ترفع ملف ZIP نفسه ولا المجلد الذي يحتوي الملفات.
2. يجب أن تشاهد index.html بجانب app.js وstyle.css ومجلد assets في أول صفحة للمستودع.
3. من Settings → Pages اختر Deploy from a branch ثم الفرع الذي رفعت عليه الملفات (غالباً main) ثم / (root)، واضغط Save. إذا كنت تستخدم docs كمصدر للنشر، ضع جميع الملفات فيه بدلاً من الجذر.
4. راقب Actions حتى تنجح عملية pages build and deployment. بعد اكتمالها افتح رابط الموقع واضغط Ctrl + Shift + R. لا تمسح بيانات الموقع حتى لا تفقد أوزانك المحلية.
5. تحقق من أسفل الصفحة: GitHub Edition · 20261031-github-01. هذا يؤكد أنك تشاهد النسخة الجديدة.

هذه نسخة HTML/CSS/JS جاهزة، لا تحتاج Node أو npm أو Build على GitHub. تعمل على دومين مخصص أو على رابط مستخدم.github.io/اسم-المستودع/؛ مسارات الصور والإشعارات نسبية.

## حدود الحفظ على GitHub Pages

GitHub Pages يستضيف الملفات الثابتة فقط؛ لا يشغّل قاعدة بيانات حسابك. هذه النسخة تحفظ الأوزان والجولات والخطة والملاحظات على المتصفح والجهاز نفسه؛ لا توجد مزامنة بين الأجهزة أو حماية بحساب. مسح بيانات المتصفح أو تغيير العنوان/المتصفح قد يفقد الحفظ. استخدم «نسخة احتياطية» لتنزيل JSON، و«استعادة نسخة» على جهاز آخر. لا توجد بيانات شخصية مسجلة داخل ملفات المشروع.

إذا كنت تستخدم نسخة OMAR / FIT ذات الحفظ الخاص بالحساب، صدّر بياناتك منها ثم استورد JSON في هذه النسخة. موقع الحفظ السحابي الموجود لديك يبقى منفصلاً؛ هذه النسخة لا تستبدل قاعدة بياناته.

الاستيراد يدمج السجلات، ولا يحذف الحالي؛ وإذا تشابهت جولة تُختار الأحدث وتُحفظ النسخة المستوردة كاملة ضمن الأرشيف. نسخة مشروع الخادم الكاملة منفصلة عن هذه النسخة ولا تعمل مباشرة على GitHub Pages.
