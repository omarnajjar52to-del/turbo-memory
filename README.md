# مشروع معرض LG — HTML / CSS / JavaScript

## التشغيل
1. فك ضغط الملف كاملًا مع الاحتفاظ بمجلد assets بجانب الملفات.
2. افتح index.html في Chrome أو Edge أو Firefox. لا يحتاج الموقع إلى npm أو أدوات بناء.
3. يمكن أيضًا رفع الملفات مباشرة إلى استضافة مواقع ثابتة. لتجربة محلية عبر HTTP، عند توفر Python:
   python -m http.server 8080
   ثم افتح http://localhost:8080

## بيانات المعرض
في أول script.js عدّل كائن SHOP:
- name.ar وname.en: اسم المعرض بالعربية والإنجليزية.
- address.ar وaddress.en: العنوان.
- whatsapp: الرقم الدولي بالأرقام فقط، مثل رمز العراق 964 متبوعًا بالرقم دون الصفر المحلي.
- phone: رقم الهاتف الظاهر.
- hours.ar وhours.en: ساعات العمل.
- mapUrl: رابط خريطة حقيقي للمعرض.

عندما يكون رقم واتساب فارغًا، يُعرض نص الاستفسار للنسخ مع تنبيه بأن التواصل غير مهيأ. لا تُرسل رسائل ولا يُستخدم رقم وهمي. عند إضافة الرقم الصحيح يفتح واتساب باستفسار يتضمن اسم المنتج ورقم الموديل؛ الإرسال بيد الزائر.

## تعديل المنتجات والأسعار والتوفّر
عدّل مصفوفة PRODUCTS في script.js. كل منتج يتضمن:
id, category, name, model, images, price, availability, features, specifications, variants.

- id: معرّف فريد وثابت.
- category: tv, fridge, washer, ac, dryer, dishwasher, kitchen, vacuum, audio.
- name: {ar:'الاسم', en:'Name'}.
- images: قائمة مسارات مثل ['assets/my-product.webp','assets/my-product-back.webp'].
- price: سعر رقمي بالدينار العراقي دون فواصل، أو null لعبارة «استفسر عن السعر».
- availability: available (متوفر)، unavailable (غير متوفر)، order (حسب الطلب).
- features: {ar:['ميزة 1','ميزة 2','ميزة 3'],en:['Feature 1','Feature 2','Feature 3']}.
- specifications: حقول مثل capacity، screen، color، resolution، type بقيم ثنائية اللغة.
- attribute: قيمة الفلتر الرقمي، مثل '65' للتلفزيون، '600' للثلاجة، '8' للغسالة.
- demo: true للمنتجات التجريبية؛ غيّرها إلى false فقط بعد إدخال بيانات المنتج الفعلية وصوره المطابقة.
- description وwarranty وdelivery: معلومات اختيارية بالعربية والإنجليزية؛ لا يُعرض ضمان مفترض عند غيابها.

مثال بنية الخيارات (داخل variants)، استخدمها فقط عند وجود خيارات فعلية:
[{label:{ar:'خيار فضي',en:'Silver option'},model:'ACTUAL-MODEL',images:['assets/actual-photo.webp'],price:900000,availability:'order',specifications:{color:{ar:'فضي',en:'Silver'}}}]

اختيار أحد الخيارات يحدّث الموديل والصورة والسعر والتوفّر والمواصفات داخل التفاصيل. المقارنة والمفضلة تحفظان المنتج الأساسي. لتسهيل مقارنة خيارات منفصلة أضف كل خيار كمنتج مستقل.

لإضافة أسماء حقول مواصفات جديدة بالعربية والإنجليزية، أضف مفتاحها في كائن TEXT.
لا يوجد حد برمجي لعدد المنتجات. الفئات التسع جاهزة ويعرض الكتالوج كل السجلات بما فيها غير المتوفرة. لا يوجد ترتيب بالأحدث لأن البيانات الحالية لا تتضمن تواريخ موثقة.

## الملفات
- index.html: البنية الدلالية وأقسام الصفحة والنوافذ.
- style.css: الهوية البصرية، RTL/LTR، الاستجابة والحركة وتقليلها.
- script.js: البيانات والترجمة والبحث والفلاتر والمفضلة والمقارنة والتفاصيل وواتساب.
- assets/: الصور المحلية بصيغة WebP.
- ASSET-SOURCES.md: مصادر الصور وملاحظة الحقوق.

## ما يعمل
البحث بالاسم/الموديل، الفئات التسع، السعر والتوفّر والسعة/الحجم، الترتيب، عدد النتائج، مسح الفلاتر، المفضلة، مقارنة حتى ثلاثة منتجات من فئة واحدة، حفظ محلي، العربية والإنجليزية، تفاصيل المنتج، الصور والتكبير، خيارات المنتج عند إدخالها، استفسارات واتساب بعد إعداد الرقم، وإيقاف/تشغيل مشاهد الواجهة.
البيانات ثابتة ولا تتصل بنظام مخزون مباشر. لا يوجد شراء أو دفع أو تقييمات أو ضمانات مختلقة.
الخط العربي IBM Plex Sans Arabic والإنجليزي Inter يُحمّلان من Google Fonts عند الاتصال. عند عدم توفر الإنترنت تُستخدم خطوط النظام؛ الصور وجافاسكريبت وCSS محلية.

## قبل الاستخدام التجاري
هذه نسخة عرض ببيانات وأسعار وموديلات DEMO صريحة وليست كتالوج LG فعليًا. صور المنتجات توضيحية ولا تؤكد مطابقة الموديلات التجريبية. استبدل البيانات والموديلات والأسعار بالبيانات الفعلية للمعرض. أضف الصور المعتمدة المرخّصة لك، وبيانات التواصل والضمان والتوصيل الصحيحة. حقوق صور العرض الترويجية لم تُتحقق؛ المصادر موثقة في ASSET-SOURCES.md ولا يمنح المشروع ترخيصًا لإعادة استخدامها تجاريًا.
